# Singular Riesz functional inequalities

Matias Delgadino, Rishabh Gvalani and Matthew Rosenzweig

**[Browse the public Lean source](https://github.com/matthewrosenzweigwork-max/DGR-Singular-LSI-Lean-Public/tree/933ab9a859aaa54a26246a4aeac1d92972c20c2d)**

The existing public formalization covers **periodic logarithmic Sobolev and Poincaré inequalities**, and **whole-space Riesz Poincaré inequalities**. The whole-space component does not claim an LSI theorem.

## Status and version

The public source snapshot is pinned at `933ab9a859aaa54a26246a4aeac1d92972c20c2d`. It contains the 312-module periodic and 154-module whole-space formalizations. Follow the linked repository's build and verification instructions. No duplicate source copy is maintained here, and linking this snapshot does not constitute a new verification run.

A completed natural-language companion manuscript is not included in this catalogue.
